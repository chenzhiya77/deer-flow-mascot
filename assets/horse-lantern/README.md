# horse-lantern

开场片沙漠夜景里的马灯挂到新马上的预览，2026-10-23。灯的单摆（`src/desert/lantern.ts`）、地上光斑、光晕和夜景调色（`Characters.tsx` 的 `LampPool` / `LampBloom` / `nightGrade`）照搬开场片，只换了挂点；整马上的灯用“柔化”摆动（只感受 25% 的竖直颠簸；原参数跑动时一直撞限位，右边特写里对比），灯体默认换成本包的墨线画法（`--style svg` 为开场片的 `HorseLantern` 原样）。只用于预览，还没接进 Remotion；渲染结果写到 `out/`，不进仓库。

## 包含

- `lantern.py` — 马灯本体：`Swing` 是 `lantern.ts` 的阻尼单摆（步长、差分、起始角、±1.2 rad 限位都相同），`ky` 是灯感受到的竖直颠簸比例（1 = 开场片，`SOFT_KY` = 0.25 为柔化），`pre` 让模拟提前开始；`flick()` 火光闪烁；`draw_lamp()` 画灯（`ink` = 默认，开场片的灯换成本包的墨线画法，加挂环；`svg` = 开场片的矢量灯，路径和颜色一一对应）；`pool()` 地上的暖色光斑，`bloom()` 灯周围的光晕，`night_grade()` 夜景调色 + 右上方的月光描边
- `lantern_preview.py` — 8 秒夜景预览，时间轴同 `horse-legs/gait_preview.py`：慢走 → 甩头＋起跑 → 跑动。左边是整马（腿 + 尾巴 + 脖子 / 鬃毛 + 臀部跟随）带着柔化摆动的灯，跑在按马速后移的夜色沙地上；右边是同一帧的两个特写（原参数 / 柔化）和最近 3 秒的摆角曲线

## 运行

```
pip install numpy opencv-python pillow pycairo
python assets/horse-lantern/lantern_preview.py                       # 8 秒预览（墨线版灯体）→ out/horse-lantern-preview.mp4
python assets/horse-lantern/lantern_preview.py --still 1.5 3.6 6.2   # 单帧 → out/horse-lantern-t1.5.png …
python assets/horse-lantern/lantern_preview.py --style svg           # 开场片原版灯体 → out/horse-lantern-preview-svg.mp4
python assets/horse-lantern/lantern_preview.py --pivot 1225 1010     # 换个挂点试（2048 画布，身体坐标）
```

- 整马来自 `../horse-legs/gait_preview.py`，找不到 `out/horse-legs/pieces.json` 时先自动生成分件（约 5 秒）。
- 编码（有 ffmpeg 用 libx264 crf 18，否则 OpenCV mp4v）、`--jobs` 并行进程数（默认 2）和中文字体规则同 `horse-upper/motion/preview.py`。
- 夜空 / 沙地颜色取自开场片的 `desert_sky.png` 与 `sandG` 渐变，只用作预览背景。

## 动作（摆角，+ = 灯往马头方向甩）

| | 慢走（0–3 s） | 甩头＋起跑（3–4 s） | 跑动（4–8 s） | 起跑后卡在限位上 |
| --- | --- | --- | --- | --- |
| 原参数（直接复用） | ±2° | −52°～+69° | ±69°，均方根 53° | 29% 的时间 |
| 柔化（竖直颠簸 ×0.25） | ±2° | −58°～+33° | −30°～+40°（5 s 后 −26°～+30°），均方根 17° | 0 |

- 单摆参数全部同 `lantern.ts`：L = 30、g = 2450、阻尼 2.1、步长 1/480 s、挂点加速度用 ±1/40 s 的二阶差分、起始 0.05 rad、限位 ±1.2 rad（±69°）。挂点的世界坐标 = 地面滚动 + 身体起伏 / 俯仰（同 `gait_preview.frame_state`），按步态的 1 单位 = 3.5 px 换回开场片单位，所以灯的固有频率（1.44 Hz）和开场片一样。
- **原参数在跑动时一直撞限位，开场片本身也是这样**：用 tsx 直接跑开场片的 `lantern.ts`，上马 / 起跑后就到 ±68.8°，6–11.5 s 里有 33% 的时间卡在限位上。原因是跑动时身体每秒起伏约 3 次，竖直加速度最高约 1.6–1.8 g，比重力还大，灯感受到的等效重力每一步都翻转一次；步频又正好约是灯固有频率的 2 倍，形成参数共振。
- 柔化只改一处：竖直加速度乘 0.25（`ky`），水平加速度和其他参数不变。慢走几乎不变，起跑时灯照样往后甩，跑动不再撞限位。要用到开场片里，就是把 `lantern.ts` 里的 `(LANTERN.g - ay)` 改成 `(LANTERN.g - 0.25 * ay)`。预览左边的整马用的就是柔化。
- 预览从 T = −2 s 起按 T = 0 的速度先跑一段，T = 0 时灯已经稳住。开场片从静止开始模拟，而马在 T = 0 已经以 337 单位/秒在走，所以开场片头 1 秒（淡入期间）灯会先甩到 −38°～+33°。
- 火光：`0.82 + 0.12·fbm1(9T, 3) + 0.06·sin(31T)`，同 `lanternState()`，和开场片逐值核对过。

## 做法

- **灯体**：`svg` 版逐条照搬 `HorseLantern` 的路径、颜色和渐变（玻璃径向渐变、随火光伸缩的火苗、栏杆、灯顶、底座和高光），整体放大到 1 单位 = 6 px；`ink` 版（默认）用同一盏灯的外形，换成本包的 15 px 墨线、金属色 #4A4044 / #86766F 和玻璃高光，只留内侧栏杆，挂点处加一个 D 形挂环，和马的画风一致。
- **夜景调色**：`nightGrade` 的颜色矩阵逐项照搬；月光描边 = 不透明区减去它平移 (−3.5, 3) 单位后的部分，模糊 0.9 单位，填 #D3E2FF ×0.85，按 1 单位 = 6 px 放大。平移时边缘按延伸取样，特写的裁切边上不会多出一条亮边。
- **光**：光斑画在地面线下 12 单位、灯正下方偏前 6 单位，透明度 0.75×火光；光晕两层（半径 380 / 120 单位，0.3 / 0.75×火光），压在马和灯上面。

## 已知差异

- 没有鸭子：开场片里鸭子落到马背上时，马身会多沉一下（`7·ring(T − mount, 2.6, 6)`），灯被再撞一次；预览里没有这一下。
- 开场片的狐狸眼睛反光、`Finishing` 的光带都读 `lanternState`，不在预览里；马跑快时的动态模糊（`riderBlur`）也没做。
- 灯的大小按马身比例（1 单位 = 6 px），摆动按步态比例（1 单位 = 3.5 px）：新马身长腿短，两个比例不一样。这样灯看起来和开场片一样大，摆起来也和开场片一样快。
