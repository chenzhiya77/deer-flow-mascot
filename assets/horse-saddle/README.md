# horse-saddle

马鞍单件素材快照（2026-10-23 更新）。

## 包含

- `saddle.png` — 当前使用件：完整马鞍，透明底，339×240；桌面 `ma-maan-wanzheng.png` 1:1 拷贝，边缘无白边，alpha 触四边
- `manifest.json` — 静态挂载与图层说明

## 说明

- 静态装配 `assets/horse-upper/` 使用无白边完整件：2048 参考画布，scale 2.2162，偏移 (554.2,930.9)。参考位在第一版 2.1281 的基础上以棕色左下角为锚放大 1.0414×（第一版偏小：左卷曲压马身、右端够不到脖子拐角），再向前移 8px，使马鞍前沿与末尾鬃毛内侧线对齐（同为 x=1299；y=960–1000 逐行核对）。奶油高光随之前移到 ma (697.9,534.9)，比参考 (690.7,534.7) 偏右 7.2px。马鞍**画在脖子之上、整件不裁不补**，右端直接盖住脖子末端角（覆盖脖子 5851px）；连接处不用参考图像素补洞。单件保持完整，供马鞍单独运动时使用。
- 无白边件与上一版是同一张画、同一 339×240 画布：silhouette IoU 0.988，落位不变；差别在 alpha 边缘——上一版半透明像素均值 RGB≈(97,92,91)，新件≈(14,11,10) 的暗色软边，因此身体上不再有白圈。
- 更早的缺口件曾以 0.8591 / (569.8,951.0) 挂载并前移 26px 让鞍口咬住鬃毛尖；该做法已退役。
- 退役副本（白边完整件、缺口件）已按清理要求删除，仓库只保留当前件；桌面母件仍在：`图片_DSs-0202.png`、`小黄鸭的马\ma-maan.png`。
- 运行时 `HorseCut` / `RidingCut` 里的马鞍仍是烘在 `public/parts-horse/body.png` 中的，未改。
- 鸭的最终形态在 `assets/final-duck/`，马头在 `assets/horse-head/`，马身上半身静态装配在 `assets/horse-upper/`。
