# horse-upper/motion

马的脖子＋鬃毛摆动预览 rig，2026-10-23。在 `horse-upper` 静态装配上让脖子、6 块鬃毛、马头和头发动起来，出 8 秒预览：慢走 → 甩头＋起跑 → 跑动。只读包内素材，不改任何成品。

## 包含

- `rig.py` — 姿态渲染：`render(neck_deg, head_deg, block_degs, hair_deg)` 返回一帧（预乘 RGBA，身体坐标系，身体与马鞍不动）
- `preview.py` — 8 秒时间轴 + 版面：左边整马（身体随步态起伏），右边局部放大（身体固定，看接缝）
- `mane.json` — 6 块鬃毛的上 / 右 / 下边与转轴、鬃毛整体轮廓；都从鬃毛示意图量出，单位是 `neck.png` 像素（示意图在 (982,120) 处与 `neck.png` 1:1 重合）

## 运行

```
pip install numpy opencv-python pillow
python assets/horse-upper/motion/preview.py                 # 8 秒预览 → out/horse-neck-mane-preview.mp4
python assets/horse-upper/motion/preview.py --still 1 3.8   # 单帧 → out/horse-neck-mane-t1.png …
```

- 有 ffmpeg 时用 libx264（crf 18）编码；没有时退回 OpenCV mp4v（画质略低）。
- `--jobs N` 并行进程数，默认 2；每个进程约 0.7 GB 内存，2 进程约 80 秒出完 240 帧。
- 输出在仓库根目录 `out/`（已被 `.gitignore` 忽略），预览视频不进仓库；重跑得到的 mp4 与已确认的 v2 逐字节相同。
- 读取：`../pieces/body.png`、`../pieces/neck.png`、`../placements.json`、`assets/horse-saddle/saddle.png`、`assets/horse-head/`（manifest + 分件，含头发层）。
- 中文字幕字体依次找微软雅黑 / 苹方 / Noto Sans SC。

## 动作（`preview.py` 的 `params()`）

| | 慢走（0–3 s） | 甩头＋起跑（3–4 s） | 跑动（4–8 s） |
| --- | --- | --- | --- |
| 脖子 | ±3.2°，每个步幅 2 次 | 叠加甩头：−9° 起、1.8 Hz 衰减振荡 | ±6.5°，每个步幅 1 次 |
| 马头 | 随脖子 | 额外 0.6× 甩头 | 随脖子 |
| 鬃毛 6 块 | 偏置 +0.5°，±2° 自上而下波动 | 反向 0.5× 甩头，逐块晚 0.05 s | 偏置 +5.5°，±5.5° 波动 |
| 头发 | ±2.5° | 反向 0.5× 甩头，晚 0.04 s | −2.5° 上 ±5° |
| 身体（只在左侧整体画面） | 起伏 ±15px，俯仰 ±1° | 过渡 | 起伏 ±64px，俯仰 ±4.6° |

- 角度以屏幕顺时针为正；起伏单位是 2048 参考画布像素。
- 甩头 3.05 s 开始；3.10–3.65 s 姿态从慢走过渡到跑动，速度 3.85 s 到顶；时间点沿用开场片的上马 / 起跑节奏，整体提前 1.9 s。
- 鬃毛波动 1.0 → 2.3 Hz，相邻块相位差 0.9 rad；步幅相位与波动相位按速度积分，换挡时不跳频。

## 做法

- **图层**：脖子 → 马头 → 身体 → 马鞍。脖子放在身体和马鞍**后面**，底边向下、鞍前向左各延伸一段（隐藏延伸），只允许在身体 / 马鞍下面和鞍前的脖子-身体缝里露出，脖子转动时接缝不会露空。胸前斜边（`neck.png` u > 303 的列）不延伸，否则前缘下会挂一道黑帘（v1 胸前粗黑线的来源，v2 已修）。
- **弯而不转**：转角沿颈轴（颈根 (1620,1225) → 头颈关节 (1947,400)）按 smoothstep(0.12, 0.60) 渐入：颈根 0°、上半段满角，鬐甲、鞍前、胸前接缝都不动；马头跟满角走，再叠加自己的 `head_deg`（绕 (1947,400)）。`render(..., bend=False)` 可切回刚性旋转对比。
- **鬃毛**：按示意图在脖子上用代码画 6 块（墨线 + 深棕填充），各自绕鬃根带内缘的转轴摆；块下垫一层阶梯状深色底（鬃毛轮廓内缩 18px，静止时被块盖住，块分开时才露出）；块和底都有柔和投影与暗边，只画在脖子可见范围内；鬃根带（原画深色带）最后叠回最上层。
- **头发**：manifest 的头发层绕发根（头发局部 (14,20)）摆，左端按 `clipPolygon` 一直藏在前耳后。

## 已知差异

- `neck.png` 外轮廓 alpha 有 5–7px 羽化（示意图约 2–3px），放大看脖子外缘比示意图软一点；原图未改。
- `rig.py` 的画布常量（延伸长度、鞍顶 y=975、鞍前缝 x≥1294、弯曲区间、`FRONT_U`）按当前 `placements.json` 调的；改落位后要复查接缝。
- 只用于预览，还没接进 Remotion 运行时；静态成品 `horse-upper.png` / `horse-bust.png` 不受影响。
