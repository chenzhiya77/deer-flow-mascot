## 对齐依据

**马鞍**：`assets/horse-saddle/saddle.png` 是**无白边完整件**（339×240，桌面 `ma-maan-wanzheng.png` 1:1 拷贝，无缺口）。上一版完整件（半透明边缘发浅灰、会露白圈）与更早的 842×596 缺口件均已退役并按清理要求删除副本，桌面母件仍在 `图片_DSs-0202.png`、`小黄鸭的马\ma-maan.png`。第一版参考落位（2.1281 / (547.2,951.0)）偏小：左侧卷曲压到马身上、右端够不到脖子拐角。按图2两处重新拟合——以马鞍棕色左下角为锚点放大 1.0414×：左侧卷曲离地；右端顺势盖住脖子末端角。在拟合位上再**向前移 8px**（x 546.2 → 554.2），让马鞍前沿与末尾鬃毛内侧线对齐：两者在 2048 画布上同为 x=1299（y=960–1000 逐行核对，前沿 1299 vs 鬃毛内线 1299–1301）；奶油高光随之到 ma (697.9,534.9)，比参考 (690.7,534.7) 偏右 7.2px。**马鞍直接画在脖子之上，整件不裁不补**，覆盖脖子 5851px。

**新脖子**：重绘件，颜色模板匹配不收敛，改用剪影配准。与参考图切出的旧脖子 `ma-bozi.png` 比：底缘（身体缝）均值 1.93px、最大 4px；喉缘均值 2.43px、最大 6px；尺度最优 2.217（用 2.2497 时底缘误差 13.6px）。鬃毛贴着脖子画，所以整件按脖子配准。

**马头**：ma-cankao 参考位 (1890.89,−93.36)（眼、鼻孔同时命中）。上一版 6px 下移是为独立鬃毛带让位，这版鬃毛已在脖子上，带子不存在，6px 退役。若要恢复，只改 `assemble.py` 的 `HEAD_XY[1]`。

## 已知差异

- **鞍座右侧**：完整鞍画在脖子**上层**，右端故意盖住脖子末端角——这是与图2唯一有意不同的一处。马鞍不裁剪、无缺口；它的右侧墨线压过脖子下缘，连接处不做取色修补。上一版放在脖子下层再修剪，才出现了看起来像缺口的切口，已撤掉。
- 第一版 2.1281 落位偏小：左侧卷曲压在马身上、右端离拐角约 11px（ma）。本次以棕色左下角为锚放大 4.14%，左卷曲抬起、右端前伸，不动左/下边；参考图左卷曲与身体线的相对高度已复现。
- 马鞍颜色沿用你的完整件（比 ma-cankao 的鞍子深一档）；右端按你的要求盖住脖子末端角、比参考多压进脖子一段，这是有意差异。完整件是 339×240，装配时放大 2.22×，纹理比躯干略软。
- 新脖子中段 [232.9,163.9,102.3]，身体 [236.4,164.7,96.7]（R−3.5 / G−0.8 / B+5.6）：新美术本身的色调，未改色。
- 新脖子后下缘与躯干的 1–2px 缝按躯干邻近色补齐；鞍沿内侧补一条新脖子边缘色贴边，范围不越鞍顶；补完无空洞、无半透明缺口，也不再保留旧脖子的颈脊高光。
- `horse-upper.png` 没有马头，颈顶右侧那条竖条是留给马头压住的，不是缺损。
